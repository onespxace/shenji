# 审计数据字段字典

| 通用字段 | 含义 | 注意事项 |
| --- | --- | --- |
| 日期 | 业务或会计日期 | 明确记账日、开票日、发货日或结算日 |
| 金额 | 交易金额 | 明确含税 / 不含税、币种和正负号 |
| 单据号 | 发票、订单、凭证或收付款编号 | 保留前导零和原始格式 |
| 对方 | 客户、供应商、员工或银行 | 关联主数据，不只依赖文本名称 |
| 来源 | 原始单据或系统来源 | 建议保留文件路径和哈希 |
| 科目 | 会计科目 | 确认辅助核算和维度 |
| 状态 | 草稿、已审核、已支付等 | 明确状态时间和操作人 |

## 建议

每个导入批次保存文件名、导出时间、筛选条件、字段映射、记录数和异常摘要。
