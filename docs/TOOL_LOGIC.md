# 工具逻辑说明

AuditDesk 的程序逻辑是确定性规则，不使用隐藏的机器学习分数。

- A01：余额重算、账面 / 银行差异、重复流水。
- A02：报告期末 ±5 天日期窗口、发票 / 发货 / 入账比较、重复组合。
- A03：三单金额差异、供应商 + 发票号重复、资料缺口。
- A04：数量滚动、数量 × 成本、负数和零成本。
- A05：发票 / 日期 / 金额重复、资料缺失、整数金额。
- A06：工时 × 费率、员工重复、负实发。
- A07：凭证借贷平衡、来源 / 摘要 / 金额指纹、大额和关键词。

阈值为示例默认值，正式项目应在项目设置、规则说明和底稿中记录调整依据。
