# AuditDesk 使用指南（Electron 桌面版）

本文档对应 Windows 桌面版（Electron）。网页版流程见 `docs/USER_GUIDE.md`。

## 第一次使用

1. 启动 `AuditDesk.exe`。
2. 在“项目总览”确认项目名称、主体和报告期间。
3. 进入“数据与导入”，导入 CSV / XLSX，或载入一个模块示例。
4. 进入“审计程序”，选择现金、收入、采购、存货、费用、薪酬或凭证模块。
5. 点击“运行检查”，查看异常明细。
6. 将需要跟进的项目登记到“底稿与证据”。

## 推荐顺序

- A01 现金与银行
- A02 收入与截止
- A03 采购与付款
- A04 存货与盘点
- A05 费用与报销
- A06 薪酬与工资
- A07 凭证与异常

每个模块都应先确认数据总体和字段口径，再解释结果。

## 数据文件建议

- 保留原始导出文件，不要直接覆盖；
- 文件名包含主体、期间和数据类型；
- 记录导出时间、筛选条件和文件哈希；
- 日期列明确是业务日期、记账日期还是开票日期；
- 金额列明确含税 / 不含税、币种和借贷方向；
- 关键字段保留稳定的单据号和来源号。

## API

研究助手不是必经步骤。配置 API 后可以辅助整理资料、解释程序和生成底稿提纲，
但不应把回答直接当作审计结论。

## 与网页版的差异

| 能力 | 桌面版 | 网页版 |
| --- | --- | --- |
| 审计程序 | 7 个业务模块（A01–A07） | 8 个通用确定性程序 |
| 导入格式 | CSV / XLSX / PDF | CSV / TSV / TXT |
| OCR | 主进程内运行 | 浏览器内本地运行 |
| 凭证检查 | 依赖桌面资源 | 10 项形式要素 + 大写金额交叉校验 |
| 部署 | 需打包 EXE | 静态站点，GitHub Pages |
