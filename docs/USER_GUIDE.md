# AuditDesk 使用教程（网页版）

本文档对应仓库内的 `web/` 版本。桌面版流程见 `docs/USER_GUIDE_DESKTOP.md`。
应用内也内置了这份教程：**使用教程与用例** 页（顶部导航），用例可一键载入并运行。

## 入口

打开站点先进**落地页**（首页）：一句话说明它是什么、能干什么，下面是 7 个模块入口。
点「进入工作台」或任意模块卡片才进工具界面；进去之后点左上角徽标（或顶栏的首页按钮、
手机端「更多」里的「返回首页」）可以回到落地页。

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 落地页 | `/`（`#/home`） | 入口页：定位说明 + 7 个模块入口 |
| 工作台 | `#/analysis` 等 | 全部功能 |
| 功能 PPT | `/deck.html` | 14 页网页式演示文稿，适合给别人介绍 |
| 部署产物 | `github-pages/` | 可直接上传的静态目录 |

功能 PPT 的操作方式：

| 按键 | 作用 |
| --- | --- |
| `←` `→` / 空格 / 回车 | 翻页 |
| `Home` / `End` | 首页 / 末页 |
| `O` | 打开总览，点缩略图跳转 |
| `F` | 全屏演示 |
| `Esc` | 退出总览 |

手机上直接左右滑动翻页；浏览器打印功能可把 14 页导出为 PDF（已配置一页一张）。

## 五个模块

1. **数据分析** —— 8 个确定性审计程序
2. **会计基础** —— 科目分类、基础问答、凭证图片检查
3. **底稿文书** —— 询证函、存货监盘表、审计调整汇总表
4. **法规速查** —— 审计准则与高频错报要点离线检索
5. **AI 问答** —— DeepSeek / Gemini / Ollama / 自定义接口

## 上手五步

### 第零步 · 从落地页进入

打开就是落地页。想直接开始就点「进入工作台」；想先了解有什么，就点对应模块卡片
（数据分析 / 会计基础 / 底稿文书 / 法规速查 / AI 问答 / 使用教程 / 设置）。
落地页上也放了「查看功能演示」和「上手教程与用例」两个入口。

### 第一步 · 导入台账

在「数据分析」页点击选择文件，或把 CSV / TSV 直接拖到虚线框。系统自动识别 UTF-8 与 GBK。

没有数据时点「载入示例台账」先熟悉界面。列名会被自动匹配到各程序所需字段，也可以手动改。

### 第二步 · 选程序并运行

左侧选择程序，确认字段映射与阈值，点「执行分析」。结果可下载为 CSV。

| 程序 | 检查内容 | 典型发现 |
| --- | --- | --- |
| 本福特定律 | 首位数字分布与卡方统计量 | 人为干预区间 |
| 重复检查 | 关键字段重复记录 | 重复报销、重复付款 |
| 断号检查 | 编号连续性 | 凭证被抽走或替换 |
| 账龄分析 | 按日期分层与金额合计 | 长期挂账、减值不足 |
| 分层汇总 | 分组求和与总体合计 | 类别间异常背离 |
| 审计抽样 | 样本量与固定种子抽取 | 可复现的选样记录 |
| 凭证筛查 | 周末、整数、大额、空摘要 | 管理层凌驾线索 |
| 试算平衡 | 借贷合计与差额 | 不平衡分录 |

### 第三步 · 留存底稿

在「底稿文书」生成询证函、监盘表、调整汇总表；把需要跟进的项目登记为待复核线索。

### 第四步 · 会计与凭证核对

「会计基础」页：

- 输入任意科目名称或四位代码，得到所属六大类
- 速答六要素、三大报表、增值税税率、利润公式
- 上传凭证图片做本地 OCR 形式检查（10 项），图片不上传
- **利润计算**：只填最底层的收入、成本、费用和税率，逐层推到净利润；点「导出表格」可把输入项、每一步计算过程、结果和恒等式校验导出成 CSV，Excel 直接打开，金额不带千分位可以直接求和
- **分录生成**：用一句话描述业务，自动匹配分录并配平

#### 分录生成怎么用

1. 在输入框里说业务，金额可以一起说：`收到股东投资款 30 万`、`收到投资款￥300,000.00`、`确认收入 1.5万元` 都能识别。
2. 系统按关键词匹配业务；**如果最高分有多条并列，会明确提示"这句话能对上多个业务"，让你确认，而不是替你选一条。**
3. 每行科目可以**单独填金额**，因为"借 原材料 + 进项税 / 贷 银行存款"这类一行对多行的分录本来就需要拆分。
4. 「业务金额」+「填入金额」用于一对一快速填；剩下没配平时点「自动补差额」，差额侧只剩一行未填时会自动补上，有多行未填会告诉你为什么补不了。
5. 状态标签只有四种：**未填金额 / 待配平 / 已配平 / 需要调整**。没填金额时显示"未填金额"，不会谎称已配平。
6. 「复制分录」把预览内容复制成纯文本；「导出表格」导出 CSV（第一列带业务名，方便多张凭证拼表）。

备查式分录（原图把几种可能来源并排列出、实际只发生一种）用 `n/m` 标出选择数，组内点另一行会自动切换而不是叠加，不会一填金额就报"多选一"。

#### 凭证识别的真实准确率

在 4 张带标准答案的测试图上（扫描件 / 轻微倾斜 / 低对比度 / 手机翻拍），
**字段命中率 80%**：前三张 90%，翻拍图只有 50%。真实凭证有手写金额、
手写签名和印章遮挡，只会更差。

换更准的模型、做图像前处理、改版面模式、分区二次识别都试过，
**没有一个能提高准确率**（详见 [`OCR_QUALITY.md`](./OCR_QUALITY.md)）。
所以本工具选择把错的位置标出来：

| 界面元素 | 含义 |
|---|---|
| 识别前 · 画质评分 | 低于 78 分说明这张图不值得识别，按提示重拍比改文字更省事 |
| 识别后 · 整页置信度 | 整页平均值，**不能**用它判断某个字段对不对 |
| 识别后 · 每条检查项的「识别 xx%」 | 该字段匹配到的词里**最低**的那个置信度 |
| 「识别置信度偏低，请重点核对」 | 低于 78% 的字段，逐一列出 |
| 整体结论降级 | 关键字段置信度不足时，不会给"形式要素基本完整"，最高只到"需要人工复核" |

要点：**整页置信度 90% 也可能藏着一个 56% 的错字。** 认错的位置要靠逐字段置信度才看得见。

### 第五步 · 用 AI 整理思路

在「AI 问答」配置服务商，把准则条文、程序清单、底稿提纲交给模型整理。**输出仅供思路参考，不构成结论。**

## 数据文件建议

- 保留原始导出文件，不要直接覆盖
- 文件名包含主体、期间与数据类型
- 记录导出时间、筛选条件与文件哈希
- 日期列明确是业务日期、记账日期还是开票日期
- 金额列明确含税/不含税、币种与借贷方向
- 断号检查需要**纯数字**编号列（如 `V-001` 无法解析，可另建 `序号` 列）

## 常见问题

**数据会上传吗？** 不会。CSV 解析、8 个审计程序、凭证 OCR 全在浏览器内完成。只有你主动发送 AI 问题时，那一条才会发给你自己配置的接口。

**为什么异常不等于错报？** 工具做的是确定性筛查，输出的是待复核线索。是否错报要结合业务实质与证据判断。

**AI 能替代准则原文吗？** 不能。模型可能记错条款编号，页面已要求以正式准则为准。

**手机能用吗？** 可以。窄屏自动切换底部标签栏，会话列表改抽屉，宽表格在容器内横向滚动。OCR 首次需下载约 17MB 本地模型。

**结果能复现吗？** 能。同一份数据与参数必然同一结果；抽样记录随机种子可完整复现。

**某个页面显示「页面加载失败」怎么办？** 那是页面资源没下载下来（网络波动、站点刚更新、
浏览器缓存了不完整的文件）。点「重新加载页面」即可；它是带时间戳的整页重载，
会绕开上一次的失败记录。**不会一直转圈**——如果一直转圈，请刷新一次页面再试。

**支持什么格式？** 网页版支持 CSV / TSV / TXT。Excel 请先另存为「CSV UTF-8」。
