# 发布验收清单

## 功能

- [ ] 桌面应用可以启动，窗口显示“项目总览”。
- [ ] 可以导入 CSV、XLSX 和 JSON。
- [ ] 七个模块均可载入样例并运行。
- [ ] SQL 工作台可以查询当前数据。
- [ ] 学习资料可以从本地资源读取。
- [ ] 底稿、证据、笔记和 API 设置可以保存。
- [ ] 导出工作区和结果不报错。

## 专业控制

- [ ] 不完整总体不能显示“通过”。
- [ ] 程序输出明确是待复核线索。
- [ ] 运行结果记录数据文件、总体记录数和运行时间。
- [ ] 导出文件不包含明文 API Key。
- [ ] 原始文件不被程序覆盖。
- [ ] 规则参数和容差写入结果摘要。

## 发布

- [ ] `release\\AuditDesk-1.0.0-portable.exe` 大小在 300–700 MB。
- [ ] 便携版可以在没有开发环境的 Windows 机器上启动。
- [ ] DuckDB 和 OCR 资源许可证随包保留。
- [ ] 应用首次启动不依赖网络。
- [ ] API 功能在未配置时不影响主流程。
